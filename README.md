# Plantrack — dağıtım

Bu depo yalnızca Plantrack'in kullanıcılara dağıtılan dosyalarını içerir.
Otomatik olarak yayınlanır; elle değiştirmeyin.

**Sürüm:** v10.2 (2026-11-13)

Windows kurulum paketi: Releases bölümünden Plantrack-Setup.exe ile tek tıkla kurulum (yönetici izni gerekmez, Node.js yoksa yönlendirir).

## İlk kurulum
1. Sağ üstten **Code → Download ZIP** ile indirip bir klasöre açın
   (ya da Releases bölümünden son sürümün zip dosyasını indirin).
2. macOS: `Kur_Mac.command` · Windows: `Kur_Windows.bat` dosyasını çalıştırın.
   Node.js 18+ gerekir.

**Windows için kolay yol:** Releases bölümünden `Plantrack-Setup-<sürüm>.exe` indirip çalıştırın
(yönetici izni gerekmez; Node.js yoksa kurulum yönlendirir).

## Güncelleme
Uygulamada **Ayarlar → Programı Güncelle → GitHub** (depo: `BeNKaYS/plantrack-dagitim`).
Token gerekmez. Güncelleme öncesi otomatik yedek alınır; verileriniz değişmez.
